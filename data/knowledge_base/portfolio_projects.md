# Portfolio Projects & GitHub Repositories

## Project 1: Cyber Security Toolkit
- **Repository**: https://github.com/deswanth12/Cyber-Security-Toolkit
- **Description**: A comprehensive Python toolkit designed for practical cybersecurity workflows, network analysis utilities, port scanning, packet inspection, and local log handling.
- **Tech Stack**: Python, SQLite, Networking, Socket Programming, Security Automation.
- **Key Features**: Modular security utilities in one unified CLI/GUI interface with persistent audit logs.

## Project 2: Student Database System
- **Repository**: https://github.com/deswanth12/studentdatabase
- **Description**: A desktop database application for managing student academic records, marks, contact info, and registration details.
- **Tech Stack**: Python, Tkinter GUI, SQLite3.
- **Key Features**: Complete CRUD operations, real-time search filtering, data export, and clean error handling.

## Project 3: Staff Management System
- **Repository**: https://github.com/deswanth12/staffdatamanagement
- **Description**: Staff record management desktop tool focused on fast employee onboarding, department assignment, salary records, and quick lookup.
- **Tech Stack**: Python, SQLite, Tkinter.
- **Key Features**: Fast search indexing, editable tables, and local file backup.

## Project 4: Library Management System
- **Repository**: https://github.com/deswanth12/Library-data-management-system
- **Description**: Desktop database application for cataloging books, managing borrower history, and tracking issue/return deadlines.
- **Tech Stack**: Python, SQLite, Tkinter.
- **Key Features**: Automated fine calculator, inventory lookup, and member transaction log.
