# Portfolio Projects & GitHub Repositories

## Project 1: JanAI — AI Civic Scheme Discovery Platform
- **Repository**: https://github.com/deswanth12
- **Description**: Intelligent multi-lingual RAG AI platform for matching citizens with government welfare schemes using semantic vector search and natural language eligibility checking.
- **Tech Stack**: React, FastAPI, RAG, FAISS / Pinecone, OpenAI / Gemini, Web Speech API.

## Project 2: EvalMesh — AI Evaluation & RAG Benchmarking Framework
- **Repository**: https://github.com/deswanth12
- **Description**: Automated LLM evaluation, RAG retrieval precision benchmarking, hallucination detection, and prompt regression testing suite.
- **Tech Stack**: Python, FastAPI, React, Ragas, Pandas, Scikit-Learn, OpenAI / Gemini.

## Project 3: Zeus Robot — Autonomous Multipurpose Robotics System
- **Repository**: https://github.com/deswanth12
- **Description**: Autonomous robotics platform combining ROS 2, SLAM indoor mapping, real-time edge AI object detection with YOLO & OpenCV, and WebSockets telemetry.
- **Tech Stack**: ROS 2, Python, OpenCV, Raspberry Pi, Arduino Mega, WebSockets.

## Project 4: Cyber Security Toolkit
- **Repository**: https://github.com/deswanth12/Cyber-Security-Toolkit
- **Description**: A comprehensive Python toolkit designed for practical cybersecurity workflows, network analysis utilities, port scanning, packet inspection, and local log handling.
- **Tech Stack**: Python, SQLite, Networking, Socket Programming, Security Automation.

## Project 5: Student Database System
- **Repository**: https://github.com/deswanth12/studentdatabase
- **Description**: A desktop database application for managing student academic records, marks, contact info, and registration details with Tkinter GUI and SQLite.
- **Tech Stack**: Python, Tkinter GUI, SQLite3.

## Project 6: Staff Management System
- **Repository**: https://github.com/deswanth12/staffdatamanagement
- **Description**: Staff record management desktop tool focused on fast employee onboarding, department assignment, salary records, and quick lookup.
- **Tech Stack**: Python, SQLite, Tkinter.

## Project 7: Library Data Management System
- **Repository**: https://github.com/deswanth12/Library-data-management-system
